# File Organiser

This script automatically organises files into folders based on their file extensions.

* Documents: `.pdf`, `.docx`, `.txt`, `.xlsx`, `.csv`
* Images: `.png`, `.jpg`
* Others: Other file types

> Before

| File | Category |
|---|---|
| report.pdf | Documents |
| image.jpg | Images |
| project.ppt | Others |

> After

| File | Folder |
|---|---|
| report.pdf | Documents |
| photo.jpg | Images |
| project.ppt | Others |

### How to run

```python
python file_organizer.py
```
