# File Organiser

This script automatically organises files into folders based on their file extensions.

* Documents: `.pdf`, `.docx`, `.txt`, `.xlsx`, `.csv`
* Images: `.png`, `.jpg`
* Others: Other file types

> Before

| File | Category |
|---|---|
| report.pdf | Document |
| photo.jpg | Image |
| project.ppt | Other |

> After

| File | Folder |
|---|---|
| report.pdf | Documents |
| photo.jpg | Images |
| project.ppt | Others |

### How to run

```python
python3 file_organizer.py
```

Enter directory path.
